# 国考刷题小程序静态设计与交互规范

## 视觉基准

- 方向：晨光学习站。
- 画布：390 × 844，适配微信小程序手机端。
- 主色：薄荷绿与天空蓝渐变，暖白背景，深灰正文。
- 气质：年轻、轻盈、专注，不使用少儿化装饰。
- 通用结构：顶部标题区、主体内容区、底部四栏导航。

## 页面与路由

| 页面 | 建议路由 | 主要内容 |
| --- | --- | --- |
| 首页 | `/pages/home/index` | 今日目标、自定义科目进度、继续刷题、错题提醒 |
| 题库 | `/pages/bank/index` | 按科目分组的私人题库、归属设置、随机练习 |
| 科目管理 | `/pages/subjects/index` | 新增、改名和删除自定义科目 |
| 练习设置 | `/pages/practice/setup` | 科目、题量、顺序、是否只练未做题 |
| 答题 | `/pages/practice/question` | 进度、题干、四个选项、收藏、提交 |
| 答案解析 | `/pages/practice/analysis` | 作答结果、正确答案、解析、知识点、下一题 |
| 练习结果 | `/pages/practice/result` | 正确率、用时、答题分布、错题回顾 |
| 错题本 | `/pages/wrong/index` | 科目筛选、错题列表、重新练习 |
| 学习统计 | `/pages/stats/index` | 周趋势、累计题量、正确率、科目正确率 |
| 我的 | `/pages/profile/index` | 学习天数、目标设置、收藏、历史、内容说明 |

## 核心跳转

| 来源 | 控件 | 行为 |
| --- | --- | --- |
| 首页 | 继续刷题 | 恢复上次记录；无记录时进入练习设置 |
| 首页 | 科目条目 | 使用该科目下的所有题库进入练习设置 |
| 首页 | 错题复习提醒 | 打开错题本 |
| 题库 | 题库卡片 | 打开该题库的练习设置 |
| 题库 | 科目选择器 | 修改题库所属科目 |
| 题库 | 管理科目 | 打开科目管理页 |
| 练习设置 | 开始练习 | 创建练习会话并进入答题页 |
| 答题 | A/B/C/D 选项 | 单选题替换当前选择；多选题切换每个选项的勾选状态 |
| 答题 | 提交答案 | 校验选择并切换到答案解析状态 |
| 答题 | 收藏 | 切换当前题收藏状态，不离开页面 |
| 答案解析 | 下一题 | 保存记录并加载下一题 |
| 答案解析 | 查看题目列表 | 打开本次练习题号面板 |
| 最后一题解析 | 完成练习 | 进入练习结果页 |
| 练习结果 | 错题回顾 | 打开本次错题的解析列表 |
| 练习结果 | 再练一组 | 复用当前设置创建新会话 |
| 错题本 | 重新练习 | 以筛选后的错题创建练习会话 |
| 底部导航 | 首页/题库/错题/我的 | 切换四个一级页面并保留各页状态 |

## 答题状态

1. 未选择：提交按钮禁用。
2. 已选择：选项使用主色描边，提交按钮启用；多选题可继续勾选或取消。
3. 正确：单选答案相同，或多选答案集合完全一致；所有正确项显示绿色。
4. 错误：漏选、多选或误选均判错；误选项显示红色，全部正确项显示绿色。
5. 内容待复核：题目底部显示“内容待复核”，不阻塞答题。
6. 数据异常：跳过非法题目并加载下一题；当前题库不可用时返回题库页。

## 数据对应

- 题目读取：从小程序本地文件目录中的私人题库分块加载。
- 错题和统计只保存题目 ID、用户答案、是否正确、耗时、答题时间。
- 解析页通过题目 ID 回查题干、选项、答案、解析和知识点。
- 资料分析题先按 `materialId` 读取共享材料，再显示题干。
