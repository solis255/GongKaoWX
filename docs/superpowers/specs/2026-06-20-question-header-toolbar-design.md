# 答题页顶部与底部工具栏调整设计

## 目标

解决不同机型下题号、答题卡文字和微信胶囊互相挤压的问题，修正解析页返回入口的视觉位置，并确保无真实答题事件的新用户错题数为 0。

## 顶部导航

答题页顶部只保留左侧圆形返回/上一题按钮和严格居中的题号，不再显示右侧“答题卡”。左侧控件为 64rpx 圆形浅色按钮：第一题显示左箭头，第二题及之后显示“上”字或回退箭头并附无障碍语义“上一题”。

解析页共享头部不再传入 `right-text="答题卡"`。共享头部的返回入口改为圆形左箭头按钮，位于胶囊下方的导航行内；标题保持屏幕水平居中。该样式同步改善目标、统计、收藏和记录等使用共享头部的页面。

## 答题卡入口

答题页底部工具栏调整为“收藏｜答题卡｜提交答案”。收藏与答题卡为等宽小工具按钮，提交答案占剩余空间。

解析页底部调整为“上一题/返回｜题卡｜下一题/完成练习”。题卡使用紧凑描边按钮，前后题按钮保持现有主次层级。三个按钮均位于底部安全区之上，不覆盖滚动内容。

## 新用户错题

首页错题提醒和错题本只从 `getWrongSnapshot(answerEvents)` 推导，不再合并 `guokao_wrong_answers` 旧 ID。旧存储键保留但不参与展示，避免删除用户本地数据的破坏性迁移。

当答题事件为空时：首页错题数为 0；错题本展示“暂时还没有错题”；本周巩固数为 0。

## 测试与验收

- 结构测试确保答题页和解析页顶部不存在“答题卡”文字，底部均存在题卡入口。
- 结构测试确保共享头部使用圆形返回按钮。
- 单元/静态测试确保首页和错题本不读取 `getWrongAnswerIds()`。
- 微信开发者工具验证 iPhone 12/13 与窄屏：顶部题号居中，返回按钮不碰胶囊，底部题卡可点击。
- 清空答题事件后验证首页和错题本均显示 0 条错题。
