# 国考刷题小程序用户进度与导航改造设计

## 目标

把首页、题库、错题本和个人中心从演示数据改为同一份真实用户数据驱动，并补齐每日目标、收藏列表、练习记录与两种练习模式。所有页面必须避开微信右上角胶囊按钮。

## 顶部安全区

应用启动时读取 `wx.getWindowInfo()` 和 `wx.getMenuButtonBoundingClientRect()`，计算状态栏高度、胶囊顶部、胶囊高度和自定义导航高度。结果保存为全局布局指标，各页面通过统一顶部栏或 CSS 变量使用，不再依赖固定 `48rpx`。

首页、题库、错题本和个人中心的首屏内容从胶囊下方开始。答题、解析、设置、统计和新增列表页面使用同一套自定义顶部栏。

## 用户数据模型

### 答题事件

每次提交答案立即保存一条事件：

```js
{
  questionId: 'verbal-001',
  moduleKey: 'verbal',
  userAnswer: 'B',
  correct: true,
  elapsedMs: 42000,
  answeredAt: 1781884536728
}
```

事件只追加、不覆盖。首页进度、错题、巩固数、练习记录和个人统计全部从事件推导，避免页面各自维护互相矛盾的计数。

### 每日目标

本地保存 `dailyGoal`，默认 20 题，可选常用值 10、20、30、50，也可输入 1–200 的整数。首页今日完成数为当天答题事件数量，完成比例最多显示 100%。首页目标卡和“我的 → 学习目标”都进入同一个设置页面。

### 收藏

收藏继续保存题目 ID 集合。答题页可切换收藏状态；“我的收藏”页面根据 ID 回查题目，支持查看、取消收藏和以收藏题创建练习。

## 统计口径

### 首页问候和日期

- 05:00–11:59：早上好，继续保持。
- 12:00–13:59：中午好，稳步前进。
- 14:00–18:59：下午好，保持专注。
- 19:00–23:59：晚上好，今天也有收获。
- 00:00–04:59：夜深了，注意休息。

右侧日期卡显示当前月、日和星期，跨天或页面重新显示时刷新。

### 科目练习

每个模块显示“曾经答对过的不同题目数 / 模块总题数”。同一道题重复答对只计一次；新用户从 0 开始。进度条按该比例计算。

### 个人中心

- 累计答题：全部答题事件数量。
- 正确率：正确事件数 ÷ 全部事件数；无记录时为 0%。
- 收藏：当前收藏题目数量。
- 连续学习：按自然日计算最近连续有答题事件的天数。

## 练习模式

### 模块练习

选择一个模块后进入练习设置，只从该模块抽题。页面标题和设置卡明确显示模块名称。

### 随机练习

从六个模块混合抽题，尽量均衡分配题量，最后统一打乱。进入设置页时显示“综合随机练习”，不预先绑定单一模块。

“只练未做题”会过滤已有答题事件的题目。如果可用题量不足，则使用全部剩余题目并在开始前提示实际题量；没有可用题目时提示用户关闭该选项。

## 错题本

错题集合定义为“最新一次作答仍然错误”的题目。某题后续答对后从当前错题集合移除，但历史错误次数保留在练习记录中。

错题分类摘要只统计当前筛选范围：

- 有错题：显示“共 N 道错题 · 本周已巩固 M 道”。
- 无错题：显示“该模块暂时没有错题”，隐藏错题列表。

“本周已巩固”定义为本周内至少有一次“历史上答错过、随后答对”的不同题目数，并遵循当前模块筛选。

空状态主按钮为“开始{模块名}专项练习”；全部分类为空时按钮为“去题库开始练习”。有错题时按钮为“重新练习 N 题”。

## 收藏与练习记录页面

### 我的收藏

按最近收藏顺序展示题目模块、题干摘要和收藏时间。点击题目进入单题练习；支持取消收藏。无收藏时显示空状态和“去题库看看”。

### 练习记录

按最后练习时间倒序展示已做过的不同题目。每行包含模块、题干摘要、作答次数、错误次数、最后练习时间和最新状态。点击可再次练习该题。错误次数统计全部历史答题事件，不因后续答对而清零。

## 路由与页面改动

- 新增 `/pages/goal/index`：每日目标设置。
- 新增 `/pages/favorites/index`：收藏题目列表。
- 新增 `/pages/history/index`：逐题练习记录。
- 首页目标卡进入目标设置。
- 题库随机练习进入综合随机设置，模块列表在随机模式下用于筛选随机题范围，不再等同于模块练习。
- 个人中心的学习目标、练习记录、我的收藏分别进入对应页面。

## 数据迁移与异常处理

保留原有错题 ID、收藏 ID、练习汇总和设置。新版本首次启动时：

1. 合法收藏和错题 ID 继续使用。
2. 旧练习汇总保留用于兼容展示，但不伪造逐题事件。
3. 缺失或损坏字段回退为空数组或默认每日目标 20。
4. 题目 ID 已失效时从列表中忽略，不阻塞页面。

## 测试与验收

- 单元测试覆盖问候、日期、每日目标校验、模块正确题数、连续学习天数和个人统计。
- 单元测试覆盖错题集合、错误次数、本周巩固数和分类空状态。
- 单元测试覆盖混合随机抽题、只练未做题、收藏列表和练习记录聚合。
- 开发者工具验证所有页面避开胶囊区域。
- 新用户首页模块计数、错题数、累计答题、正确率和收藏均为 0。
- 完成一次正确与一次错误作答后，首页、错题、我的和练习记录同步更新。
- 模块练习与随机练习产生不同的题目来源范围。
- 每日目标从首页和个人中心进入同一页面，保存后首页立即更新。
