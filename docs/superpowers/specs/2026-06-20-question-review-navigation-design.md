# 刷题回看、题目来源与个人指标导航设计

## 目标

完善答题过程中的题目列表、上一题回看、来源查看和长解析滚动；同时让“我的”页三个统计指标分别进入对应页面。保持现有年轻活力学习应用视觉风格，不联网补充题目来源。

## 答题卡

新增 `/pages/question-card/index`，展示当前会话全部题号：

- 当前未提交题：绿色描边。
- 已答对题：绿色实底。
- 已答错题：红色实底。
- 尚未到达的题：灰色锁定，不可点击。

页面显示已完成数、正确数和错误数。点击当前题回到答题页；点击已答题进入该题解析；点击未来题只提示“请按顺序完成前面的题目”。答题页与解析页的“答题卡”入口都进入该页面，不再显示 Toast。

## 会话回看

在练习会话服务中新增按索引跳转能力。跳转到已答题时恢复当时的用户答案并保持 `submitted: true`；跳转到最新未答题时恢复未提交状态。回看不得新增答题事件、改变正确率或重复计算用时。

答题页和解析页均提供“上一题”：

- 第一题显示“返回”，执行原页面返回行为。
- 第二题及之后显示“上一题”，进入前一题解析。
- 解析页“下一题”进入下一道已答题解析，或进入最新未答题答题页。

未来题不能通过题卡或上一题/下一题导航提前进入。

## 顶部布局

答题页采用三段式自定义顶栏：左侧为返回/上一题，中间为题号，右侧“答题卡”位于微信胶囊左边。中间题号使用独立绝对居中区域，并为左右控件预留安全宽度，避免窄屏和不同胶囊位置造成重叠。

解析页继续使用共享头部组件，其右侧安全距离沿用全局胶囊指标。

## 解析滚动

解析页改为全高纵向布局：顶部栏固定，正文使用 `scroll-view`，底部操作栏固定。正文底部增加与操作栏等高的内边距。

题干摘要取消固定高度截断，材料、完整题干、选项、作答结果、答案解析和知识点均可通过下滑查看。底部按钮不会覆盖最后一段内容。

## 题目来源

仅使用题目 JSON 已有的 `sourceRefs` 数组，不联网搜索。来源区域行为：

- 有来源时，“查看本题来源”可展开/收起来源列表。
- 每条展示标题、类型和发布日期。
- 点击某条来源调用剪贴板 API 复制其 URL，并提示“来源链接已复制”。不使用 `web-view`，避免业务域名白名单限制。
- 无来源时不展示来源入口。
- URL 缺失的来源只展示文本，不提供复制操作。

## “我的”指标导航

三个指标改为独立点击区域：

- 累计答题 → `/pages/history/index`
- 正确率 → `/pages/stats/index`
- 收藏 → `/pages/favorites/index`

视觉布局保持不变，通过轻微按压态和独立点击区域表达可操作性。

## 测试与验收

- 单元测试覆盖按索引跳转、已答状态恢复、未来题锁定和前后题导航。
- 结构测试覆盖新增题卡路由、页面文件和事件处理器。
- 静态测试确保答题卡入口不再调用 Toast，来源入口只消费 `sourceRefs`。
- 微信开发者工具验证窄屏与 iPhone 12/13：题号、答题卡和胶囊不重叠。
- 验证长题干/长解析能滚动到底，底部按钮不遮挡内容。
- 验证回看不会增加答题事件或改变统计。
- 验证“我的”三个指标分别进入三个不同页面。
